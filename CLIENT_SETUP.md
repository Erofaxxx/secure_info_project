# 💻 Инструкция для клиентов SecureChat

Сервер запущен и работает на IP: **167.172.116.12**

---

## 🪟 Windows

### Шаг 1: Установите Python

1. Скачайте Python 3.8+ с [python.org](https://www.python.org/downloads/)
2. **ВАЖНО:** При установке отметьте галочку "Add Python to PATH"
3. Установите Python

### Шаг 2: Проверьте установку

Откройте **Командную строку** (Win+R → `cmd` → Enter) и введите:
```cmd
python --version
```
Должно показать: `Python 3.x.x`

### Шаг 3: Скачайте проект

**Вариант A: Через Git (если установлен)**
```cmd
git clone https://github.com/Erofaxxx/secure_info_project.git
cd secure_info_project
git checkout claude/e2e-encrypted-messenger-011CUzpDu63wQ35htfxyRyH3
```

**Вариант B: Скачайте ZIP**
1. Получите архив с файлами проекта
2. Распакуйте в удобную папку (например, `C:\SecureChat`)
3. Откройте командную строку в этой папке:
   - Откройте папку в Проводнике
   - В адресной строке введите `cmd` и нажмите Enter

### Шаг 4: Установите зависимости

```cmd
pip install -r requirements.txt
```

Если ошибка, попробуйте:
```cmd
python -m pip install -r requirements.txt
```

### Шаг 5: Запустите клиент

**Способ 1 - Двойной клик:**
```cmd
Дважды кликните на файл: run_client.bat
```

**Способ 2 - Командная строка:**
```cmd
python client.py
```

### Шаг 6: Подключитесь к серверу

1. В открывшемся окне введите IP сервера:
   ```
   167.172.116.12
   ```

2. Нажмите Enter

3. **Регистрация** (первый раз):
   - Нажмите кнопку "Регистрация"
   - Введите желаемое имя пользователя (например: `alice`)
   - Придумайте пароль (минимум 4 символа, например: `1234`)
   - Нажмите "Регистрация"

4. **Вход** (после регистрации или если уже зарегистрированы):
   - Введите ваш username
   - Введите пароль
   - Нажмите "Войти"

5. **Готово!** Можете общаться 🎉

## ❓ Решение проблем

### "Connection refused" или не могу подключиться

**Проверьте:**
1. Сервер запущен? (спросите администратора)
2. Правильно ввели IP: `167.172.116.12`
3. Интернет работает?

**Тест подключения:**

Windows:
```cmd
telnet 167.172.116.12 5555
```

macOS/Linux:
```bash
nc -zv 167.172.116.12 5555
# или
telnet 167.172.116.12 5555
```

Должно показать "Connected" или "succeeded".

### "ModuleNotFoundError" или ошибки импорта

**Переустановите зависимости:**
```bash
pip3 install --upgrade -r requirements.txt
```

Или вручную:
```bash
pip3 install customtkinter cryptography Pillow bcrypt
```

### GUI не запускается (Linux)

**Установите Tkinter:**
```bash
# Ubuntu/Debian
sudo apt install python3-tk

# Fedora
sudo dnf install python3-tkinter
```

### Ошибка "pip: command not found"

**Windows:**
```cmd
python -m pip install -r requirements.txt
```

**macOS/Linux:**
```bash
python3 -m pip install -r requirements.txt
```

### Чёрный экран или окно не появляется

1. Проверьте что X11/Xorg запущен (Linux)
2. Попробуйте перезапустить клиент
3. Обновите графические драйвера

### "Username already exists"

Этот username уже занят. Выберите другой!

### Не вижу других пользователей в списке

1. Убедитесь что вы вошли в систему (не просто зарегистрировались)
2. Другие пользователи должны быть тоже зарегистрированы
3. Перезапустите клиент

## 🔐 Безопасность

### Ваши данные защищены!

- ✅ Все сообщения зашифрованы **end-to-end**
- ✅ Сервер **не может** прочитать ваши сообщения
- ✅ Только вы и получатель видите содержимое
- ✅ Используется шифрование RSA-2048 + AES-128

### Что хранится на сервере?

- Ваш username (открытый)
- Хеш пароля (не сам пароль!)
- Ваш публичный ключ (для E2E)
- Зашифрованные сообщения (нечитаемые)

### Что НЕ хранится?

- ❌ Пароли в открытом виде
- ❌ Приватные ключи
- ❌ Расшифрованные сообщения
