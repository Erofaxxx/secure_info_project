# 🔒 SecureChat - E2E Encrypted Messenger

Защищённый мессенджер с end-to-end шифрованием для университетского проекта по защите информации.

## 📋 Описание

SecureChat - это кроссплатформенный мессенджер с **настоящим end-to-end шифрованием**. Сервер не может прочитать ваши сообщения, так как они шифруются на устройстве отправителя и расшифровываются только на устройстве получателя.

### ✨ Основные возможности

- ✅ **End-to-End шифрование** (RSA + AES)
- ✅ Регистрация и авторизация пользователей
- ✅ До 5 чатов одновременно
- ✅ Сохранение истории переписки
- ✅ Красивый тёмный интерфейс
- ✅ Кроссплатформенность (Windows, macOS, Linux)
- ✅ Уведомления о новых сообщениях

### 🔐 Как работает E2E шифрование

1. **Генерация ключей**: При запуске каждый клиент генерирует пару RSA ключей (2048 бит)
   - Приватный ключ остаётся на устройстве (НИКОГДА не покидает его!)
   - Публичный ключ отправляется на сервер

2. **Отправка сообщения**:
   ```
   Отправитель                                  Получатель
   ──────────                                  ──────────

   1. Текст: "Привет!"
   2. Генерация случайного AES ключа
   3. Шифрование текста AES ключом → EncryptedText
   4. Шифрование AES ключа публичным RSA ключом получателя → EncryptedKey
   5. Отправка на сервер: (EncryptedText, EncryptedKey)

   Сервер просто пересылает зашифрованные данные →

                                                1. Получение (EncryptedText, EncryptedKey)
                                                2. Расшифровка AES ключа своим приватным RSA ключом
                                                3. Расшифровка текста восстановленным AES ключом
                                                4. Чтение: "Привет!"
   ```

3. **Почему сервер не может прочитать сообщения?**
   - AES ключ зашифрован публичным ключом получателя
   - Расшифровать его может только приватный ключ получателя
   - Сервер не имеет приватных ключей пользователей
   - ✅ **Это и есть настоящее E2E шифрование!**

## 🚀 Установка и запуск

### Требования

- Python 3.8 или выше
- pip

### 1. Установка зависимостей

```bash
# Клонируйте репозиторий или скачайте файлы
cd secure_info_project

# Установите зависимости
pip install -r requirements.txt
```

### 2. Запуск сервера

На сервере (или локально для тестирования):

```bash
python server.py
```

Сервер запустится на порту 5555 и создаст файл базы данных `messenger.db`.

### 3. Запуск клиента

**Локальное тестирование:**
```bash
python client.py
# Оставьте поле пустым или введите: localhost
```

**Подключение к удалённому серверу:**
```bash
python client.py
# Введите IP адрес сервера, например: 164.92.XXX.XXX
```

Или передайте адрес сервера как аргумент:
```bash
python client.py 164.92.XXX.XXX
```

## 🔧 Технологии

### Клиент
- **CustomTkinter** - Современный GUI фреймворк
- **cryptography** - Библиотека для шифрования
- **socket** - Сетевое взаимодействие

### Сервер
- **socket** - TCP сервер
- **SQLite** - База данных
- **bcrypt** - Хеширование паролей
- **threading** - Многопоточность для обработки клиентов

### Безопасность
- **RSA 2048 бит** - Асимметричное шифрование для обмена ключами
- **AES-128 (Fernet)** - Симметричное шифрование для сообщений
- **bcrypt** - Хеширование паролей на сервере
- **OAEP padding** - Защита RSA шифрования
- **SHA-256** - Хеш функция

## 🔍 Проверка безопасности

### Что зашифровано:
- ✅ Сообщения между пользователями (E2E)
- ✅ Пароли в базе данных (bcrypt hash)

### Что хранится на сервере:
- Username (открытый текст)
- Password hash (bcrypt)
- Публичные ключи (не секретные по определению)
- Зашифрованные сообщения (нечитаемые без приватного ключа)
- Зашифрованные AES ключи (нечитаемые без приватного ключа)

### Что НЕ хранится на сервере:
- ❌ Приватные ключи пользователей
- ❌ Расшифрованные сообщения
- ❌ AES ключи в открытом виде
- ❌ Пароли в открытом виде

## 🎓 Для преподавателя

### Ключевые особенности реализации:

1. **Настоящее E2E шифрование**: Сервер физически не может расшифровать сообщения
2. **Гибридная криптография**: RSA для обмена ключами + AES для быстрого шифрования
3. **Безопасное хранение паролей**: bcrypt с автоматической солью
4. **Кроссплатформенность**: Работает на Windows, macOS, Linux без изменений
5. **Современный GUI**: CustomTkinter с тёмной темой
