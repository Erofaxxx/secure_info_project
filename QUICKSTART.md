# ⚡ Быстрый старт SecureChat

Краткая инструкция для быстрого запуска проекта.

## 📦 Установка (5 минут)

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите сервер
python server.py

# 3. В другом терминале запустите клиент
python client.py
# Введите: localhost
```

## 👥 Первое использование

### Сервер (Terminal 1)

```bash
python server.py
```

Вы увидите:
```
🚀 Сервер мессенджера запущен на 0.0.0.0:5555
Ожидание подключений...
```

### Клиент 1 - Alice (Terminal 2)

```bash
python client.py
```

1. Адрес сервера: `localhost` (Enter)
2. Нажмите **"Регистрация"**
3. Username: `alice`
4. Password: `1234`
5. Нажмите **"Регистрация"**
6. Нажмите **"Войти"**

### Клиент 2 - Bob (Terminal 3)

```bash
python client.py
```

1. Адрес сервера: `localhost` (Enter)
2. Зарегистрируйтесь как `bob` / `1234`
3. Войдите

### Отправка сообщений

1. **У Alice:** Кликните на `bob` в списке слева
2. Введите сообщение: `Привет, Bob!`
3. Нажмите Enter или "Отправить"
4. **У Bob:** Кликните на `alice` - увидите сообщение

## 🔐 Проверка E2E шифрования

Пока клиенты общаются, проверьте базу данных:

```bash
sqlite3 messenger.db
```

```sql
-- Посмотрите пользователей
SELECT username FROM users;

-- Посмотрите сообщения (они зашифрованы!)
SELECT sender, receiver, substr(encrypted_message, 1, 50) FROM messages;

-- Выход
.quit
```

Вы увидите, что сообщения выглядят как случайный набор символов - они зашифрованы!

## ❓ Частые вопросы

**Q: Ошибка "Connection refused"**
```
A: Убедитесь что сервер запущен и доступен
   Проверьте IP адрес
   Проверьте firewall (порт 5555)
```

**Q: Ошибка импорта модулей**
```
A: Установите зависимости: pip install -r requirements.txt
```

**Q: Клиент не видит других пользователей**
```
A: Обновите список: перезапустите клиент
   Или добавьте кнопку обновления
```

**Q: Сообщения не расшифровываются**
```
A: Это нормально для ИСХОДЯЩИХ сообщений (они зашифрованы для получателя)
   Входящие сообщения должны расшифровываться
```

### Ключевые моменты

✅ **Настоящее E2E**: Сервер физически не может расшифровать сообщения

✅ **Безопасность**:
- RSA 2048 бит для обмена ключами
- AES для шифрования сообщений
- bcrypt для паролей
- Новый ключ для каждого сообщения

✅ **Кроссплатформенность**: Работает везде где есть Python

✅ **Простота**: Понятный код, хорошо документирован
