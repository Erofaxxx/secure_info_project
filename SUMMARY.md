# 🎉 SecureChat - Проект готов!

## ✅ Что создано

Полноценный кроссплатформенный мессенджер с **настоящим end-to-end шифрованием** для вашего университетского проекта по защите информации.

## 📦 Состав проекта

### 🔧 Основные компоненты (3 файла)

1. **server.py** (13 KB)
   - TCP сервер на сокетах
   - Многопоточная обработка клиентов
   - База данных SQLite
   - Хеширование паролей bcrypt
   - Управление публичными ключами

2. **client.py** (20 KB)
   - Красивый GUI на CustomTkinter

   - Отправка/получение сообщений
   - Автоматическая расшифровка

3. **encryption.py** (5.6 KB)
   - Генерация RSA ключей (2048 бит)
   - Гибридное шифрование RSA + AES
   - End-to-end encryption
   - Каждое сообщение = новый ключ

## 🎯 Ключевые особенности

### ✅ Настоящее E2E шифрование

- **RSA 2048 бит** для обмена ключами
- **AES-128 (Fernet)** для сообщений
- **Гибридная схема** (скорость + безопасность)
- **Приватные ключи НИКОГДА не покидают клиента**
- **Сервер физически не может прочитать сообщения**

### ✅ Безопасность

- bcrypt хеширование паролей
- OAEP padding для RSA
- Новый AES ключ для каждого сообщения
- Зашифрованное хранение в БД

### ✅ Красивый интерфейс

- Тёмная тема (не полностью чёрная)
- Минималистичный дизайн
- Похож на Telegram
- Список чатов + окно переписки

### ✅ Кроссплатформенность

- Windows
- macOS
- Linux
- Один код для всех платформ

### ✅ Функциональность

- Регистрация новых пользователей
- Авторизация с проверкой пароля
- До 5 чатов одновременно
- Сохранение истории переписки
- Автоматические уведомления

## 🚀 Как использовать

### Локальное тестирование (3 терминала)

**Terminal 1 - Сервер:**
```bash
python server.py
```

**Terminal 2 - Alice:**
```bash
python client.py
# Введите: localhost
# Зарегистрируйтесь: alice / 1234
```

**Terminal 3 - Bob:**
```bash
python client.py
# Введите: localhost
# Зарегистрируйтесь: bob / 1234
```

Общайтесь между Alice и Bob!

### С удалённым сервером

1. Арендуйте Droplet на Digital Ocean (6$/месяц)
2. Следуйте **SERVER_SETUP.md**
3. Запустите сервер на Ubuntu
4. Подключайтесь клиентами с любых компьютеров

## 🔐 Проверка безопасности

### Что зашифровано:

✅ Все сообщения между пользователями (E2E)
✅ Пароли в базе данных (bcrypt)

### Что хранится на сервере:

- Username (открытый текст)
- Password hash (bcrypt, необратимый)
- Публичные ключи (они и должны быть публичными)
- Зашифрованные сообщения (нечитаемые)
- Зашифрованные AES ключи (нечитаемые без приватного ключа)

### Что НЕ хранится на сервере:

❌ Приватные ключи пользователей
❌ Расшифрованные сообщения
❌ AES ключи в открытом виде
❌ Пароли в открытом виде
