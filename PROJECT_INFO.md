## 🔑 Ключевые компоненты

### server.py - Серверная часть
```python
Основные функции:

├── login_user()             # Аутентификация
├── get_users()              # Список пользователей

├── get_messages()           # Получение истории чата
└── handle_client()          # Обработка команд клиента
```

### client.py - Клиентская часть
```python
Основные функции:
├── connect_to_server()      # Подключение по TCP
├── register()               # Регистрация + отправка публичного ключа
├── login()                  # Вход в систему
├── send_message()           # Шифрование и отправка сообщения
├── get_messages()           # Получение и расшифровка сообщений
│
└── GUI компоненты:
    ├── show_login_screen()      # Экран входа/регистрации
    ├── show_main_screen()       # Главный экран мессенджера
    ├── load_users()             # Загрузка списка чатов
    ├── load_chat()              # Загрузка переписки
    └── display_message()        # Отображение сообщения
```

### encryption.py - E2E шифрование
```python
Класс E2EEncryption:
├── generate_keys()              # Генерация RSA ключей (2048 бит)
├── get_public_key_string()      # Экспорт публичного ключа (PEM)
├── load_public_key_from_string()# Импорт публичного ключа
├── encrypt_message()            # Гибридное шифрование (RSA + AES)
│   ├── Fernet.generate_key()   # Случайный AES ключ
│   ├── fernet.encrypt()        # Шифрование сообщения AES
│   └── rsa.encrypt()           # Шифрование AES ключа RSA
└── decrypt_message()            # Расшифровка
    ├── rsa.decrypt()           # Расшифровка AES ключа
    └── fernet.decrypt()        # Расшифровка сообщения
```

## 🔐 Как работает E2E шифрование

```
┌─────────────────────────────────────────────────────────────┐
│ ОТПРАВКА СООБЩЕНИЯ "Привет, Bob!"                           │
└─────────────────────────────────────────────────────────────┘

Alice                         Server                         Bob
──────                       ────────                       ─────

1. Запрашивает              2. Возвращает                3. (ждёт)
   публичный ключ Bob ────▶    публичный ключ Bob ───▶
                              (из базы данных)

4. Генерирует
   случайный AES ключ
   K = random()

5. Шифрует сообщение
   M_enc = AES(K, "Привет, Bob!")

6. Шифрует ключ
   K_enc = RSA(Bob_PublicKey, K)

7. Отправляет на сервер ──▶ 8. Получает:               9. (ждёт)
   {                           sender: Alice
     M_enc,                     receiver: Bob
     K_enc                      M_enc, K_enc
   }
                               НЕ МОЖЕТ РАСШИФРОВАТЬ!
                               (нет приватного ключа Bob)

                               Сохраняет в БД AS-IS

                            10. Пересылает Bob ──────▶ 11. Получает:
                                                           M_enc, K_enc

                                                       12. Расшифровывает:
                                                           K = RSA_decrypt(
                                                               Bob_PrivateKey,
                                                               K_enc
                                                           )

                                                       13. Расшифровывает:
                                                           M = AES_decrypt(
                                                               K,
                                                               M_enc
                                                           )

                                                       14. Читает:
                                                           "Привет, Bob!"
```

## 🗄️ Структура базы данных

### Таблица `users`
| Колонка       | Тип       | Описание                          |
|---------------|-----------|-----------------------------------|
| id            | INTEGER   | PRIMARY KEY AUTOINCREMENT         |
| username      | TEXT      | UNIQUE, имя пользователя          |
| password_hash | TEXT      | bcrypt хеш пароля                 |
| public_key    | TEXT      | RSA публичный ключ (PEM format)   |
| created_at    | TIMESTAMP | Дата регистрации                  |

### Таблица `messages`
| Колонка           | Тип       | Описание                              |
|-------------------|-----------|---------------------------------------|
| id                | INTEGER   | PRIMARY KEY AUTOINCREMENT             |
| sender            | TEXT      | Отправитель (username)                |
| receiver          | TEXT      | Получатель (username)                 |
| encrypted_message | TEXT      | AES зашифрованное сообщение (base64)  |
| encrypted_key     | TEXT      | RSA зашифрованный AES ключ (base64)   |
| timestamp         | TIMESTAMP | Время отправки                        |

**Важно:** Сервер хранит только зашифрованные данные!

### Ключевые моменты для оценки

✅ **Настоящее E2E шифрование**
- Сервер физически не может расшифровать
- Приватные ключи не покидают клиенты

✅ **Правильная криптография**
- RSA 2048 бит
- AES-128 (Fernet)
- bcrypt для паролей
- OAEP padding

✅ **Кроссплатформенность**
- Windows, macOS, Linux

✅ **Хорошая архитектура**

✅ **Безопасность сервера**
