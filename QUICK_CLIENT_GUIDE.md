# ⚡ Быстрая инструкция - SecureChat

**IP сервера:** `167.172.116.12`

---

## Windows (3 минуты)

```cmd
# 1. Установите Python с python.org (галочка "Add to PATH"!)

# 2. Скачайте проект и откройте папку в cmd

# 3. Установите:
pip install -r requirements.txt

# 4. Запустите:
python client.py
# Введите: 167.172.116.12

# 5. Зарегистрируйтесь и войдите!
```
